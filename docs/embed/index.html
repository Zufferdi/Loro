Embeds disponibles

Visualisations standalone à intégrer dans vos articles. Chaque embed est une iframe responsive qui adapte sa hauteur automatiquement (via postMessage). Licence : CC BY-SA 4.0 — attribution requise.

Top 30 bénéficiaires par année

Les 30 plus grandes attributions de la Loterie Romande, par année (2021–2025), avec sélecteur d'année interactif et bandeau de cumul.

→ Prévisualiser top30.html
Code à intégrer (copier-coller)
<iframe src="https://zufferdi.github.io/Loro/embed/top30.html"
        width="100%" height="900"
        style="border:0;border-radius:8px"
        loading="lazy"
        title="Loro · Top 30 bénéficiaires">
</iframe>
Options via query string : ?compact=1 (chrome minimale), ?theme=dark ou ?theme=light (force le thème).

Recherche d'organisation

Champ de recherche full-text sur 12 363 organisations bénéficiaires 2021–2025. Les lecteurs tapent un nom et voient les montants par année, sparkline 5 ans, tendance.

→ Prévisualiser find-org.html
Code à intégrer
<iframe src="https://zufferdi.github.io/Loro/embed/find-org.html"
        width="100%" height="600"
        style="border:0;border-radius:8px"
        loading="lazy"
        title="Loro · Trouvez votre organisation">
</iframe>
Au premier focus, l'embed charge ~2 MB d'index (lazy). Bien adapté à un article avec contexte.

Trajectoires 5 ans

300 plus grands bénéficiaires avec leur évolution annuelle. Filtres par catégorie (hausses, baisses, one-shots, stables).

→ Prévisualiser trajectories.html
Code à intégrer
<iframe src="https://zufferdi.github.io/Loro/embed/trajectories.html"
        width="100%" height="3000"
        style="border:0;border-radius:8px"
        loading="lazy"
        title="Loro · Trajectoires 5 ans">
</iframe>

Auto-resize de la hauteur via postMessage : si l'iframe écoute 'loro:embed:resize', elle reçoit la hauteur exacte du contenu. Voir un script d'exemple côté parent dans la documentation GitHub.
